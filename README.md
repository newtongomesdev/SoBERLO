## 🌟 About SoBERLO: The Best Open-Source Sobriety Tracker

**SoBERLO** is a professional-grade, privacy-focused mental health and well-being application designed to help users track their sobriety journey, overcome addiction, and build healthier daily habits. Whether you're looking for an alcohol tracker, a quitting smoking app, or a general habit builder, SoBERLO adapts to your needs.

Unlike most trackers on the market, SoBERLO is **100% Offline-First**. All your sensitive information, from daily mood logs to addiction trigger tracking, is safely stored **only on your local device**. In Version 1.1, we introduced local intelligence that analyzes your data without ever needing an internet connection.

## ✨ Features

- 📱 **PWA Support:** Install SoBERLO as a native app on your phone for a seamless offline experience.
- 🌓 **Dark Mode:** Eye-friendly dark interface that respects your system settings.
- 💾 **Backup & Restore:** Securely export your local data to a JSON file and restore it anytime.
- 🚀 **Multi-Tracker Support:** Track multiple habits simultaneously (e.g., Alcohol, Smoking, and Social Media) with independent counters.
- 🧠 **Neuro-Insight Engine:** Proprietary local analysis that identifies your "Danger Zones," mood correlations, and provides actionable advice—all with zero external AI dependencies.
- 💰 **Money Saved Calculator:** Automatically calculate how much money you've saved since starting your journey.
- 📝 **Advanced Journaling:** Dedicated free-writing journal to log detailed thoughts and daily progress.
- 🔒 **Absolute Privacy:** Offline-first architecture. No AI servers, no tracking, no cloud.
- 🛡️ **PIN Protection:** Add an extra layer of privacy with a custom 4-digit lock screen.
- ⏱️ **Live Sobriety Counter:** Track your journey down to the exact second.
- 🔥 **Craving Tracker & Statistics:** Log your triggers, measure craving intensity, and view your mood trends through interactive charts.
- 🏆 **Gamification:** Unlock achievements and celebrate milestones with satisfying confetti animations!
- 🆘 **SOS & Grounding:** A dedicated emergency tab featuring the 5-4-3-2-1 breathing technique and a quick-dial custom emergency contacts list.
- 🌐 **Bilingual Support:** Instantly switch between English and Portuguese (PT-BR) without losing your state.

## 🛠 Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS v4
- **Routing/SEO:** React Helmet Async
- **Data Visualization:** Recharts
- **Gamification:** Canvas Confetti
- **Document Export:** jsPDF

## 🚀 Getting Started

To run SoBERLO locally on your machine, follow these steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/soberlo.git
   cd soberlo
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to `http://localhost:3000` to view the app!

## 🌍 Deployment (Vercel Ready)

SoBERLO is live at **[soberlo.vercel.app](https://soberlo.vercel.app)**.

The project is pre-configured for a flawless deployment on **Vercel**, complete with Advanced Technical SEO features out of the box.

- `vercel.json` included for proper SPA routing and security headers.
- `robots.txt` and `sitemap.xml` configured for search engine crawling.
- **Dynamic SEO:** Rich Open Graph tags and Schema.org `JSON-LD` structured data injected via Helmet.

**To deploy your own instance:**
1. Push your code to a GitHub repository.
2. Import the project in your Vercel Dashboard.
3. Vercel will automatically detect Vite and run `npm run build`.
